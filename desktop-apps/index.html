Desktop Applications Integration

Desktop apps supporting custom OpenAI or Anthropic base URLs.

General Rule

Most desktop apps that allow setting a custom OpenAI or Anthropic endpoint work seamlessly with AgentRouter.

  • Claude / Anthropic style → Base URL: https://agentrouter.org (no /v1)
  • OpenAI style → Base URL: https://agentrouter.org/v1

Paste your AgentRouter API key in the API Key field.

Claude Desktop

  1. Open Claude Desktop settings.
  2. Locate “Custom Provider” / “API” / “Advanced” settings.
  3. Set Base URL to https://agentrouter.org
  4. Paste your API key.
  5. Select model (claude-opus-4-8 or claude-opus-5).

Any Other Desktop App

Fill in the application's configuration fields:

  • API Key: Your AgentRouter API key
  • Base URL: https://agentrouter.org or https://agentrouter.org/v1
  • Model: gpt-5.6-sol, claude-opus-4-8, or claude-opus-5
