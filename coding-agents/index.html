Coding Agents & IDE Integration

Official tools & coding assistants. Integrates directly without WAF issues.

Claude Code CLI Claude Code VS Code Cline Cursor Roo Code / Kilo Code

Claude Code CLI

  1. Install: npm install -g @anthropic-ai/claude-code
  2. Set env vars (macOS/Linux): 
    export ANTHROPIC_BASE_URL=https://agentrouter.org
export ANTHROPIC_AUTH_TOKEN=sk-your-key
export ANTHROPIC_API_KEY=sk-your-key
export ANTHROPIC_MODEL=claude-opus-4-8
  3. Windows PowerShell: 
    $env:ANTHROPIC_BASE_URL="https://agentrouter.org"
$env:ANTHROPIC_AUTH_TOKEN="sk-your-key"
$env:ANTHROPIC_API_KEY="sk-your-key"
$env:ANTHROPIC_MODEL="claude-opus-4-8"
  4. Run: claude

Note: Base URL has no /v1

Claude Code (VS Code)

  1. Install the official Claude Code extension in VS Code.
  2. Open Settings JSON (Cmd/Ctrl+Shift+P → “Open User Settings (JSON)”).
  3. Add environment configuration: 
    {
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "sk-your-key" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://agentrouter.org" },
    { "name": "ANTHROPIC_MODEL", "value": "claude-opus-4-8" }
  ],
  "claudeCode.disableLoginPrompt": true
}
  4. Reload window and test.

Cline

  1. Install Cline extension in VS Code.
  2. Open Cline panel → Settings.
  3. For Claude models:
    API Provider = Anthropic
    Use custom base URL = ✅
    Base URL = https://agentrouter.org (no /v1)
    API Key = your key
    Model = claude-opus-4-8
  4. For GPT models:
    API Provider = OpenAI Compatible
    Base URL = https://agentrouter.org/v1
    Model = gpt-5.6-sol

Cursor IDE

  1. Open Cursor Settings → Models.
  2. Paste your AgentRouter API key in the OpenAI API Key field.
  3. Enable “Override OpenAI Base URL”.
  4. Set Base URL to https://agentrouter.org/v1
  5. Save settings and select model (e.g. gpt-5.6-sol or claude-opus-4-8).

Note: Free Cursor tier may enforce auto mode restrictions.

Roo Code / Kilo Code

  1. Create a new Provider Profile in extension settings.
  2. Claude: Provider = Anthropic + custom URL
    Base URL = https://agentrouter.org
    Model = claude-opus-4-8
  3. GPT: Provider = OpenAI Compatible
    Base URL = https://agentrouter.org/v1
    Model = gpt-5.6-sol

Important Rule

  • Claude models → Base URL without /v1 (https://agentrouter.org)
  • GPT / OpenAI-compatible → Base URL with /v1 (https://agentrouter.org/v1)
  • Do not mix the two base URLs.
