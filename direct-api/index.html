Direct API (Raw HTTP / cURL)

Using AgentRouter's base URL straight in your own app/codebase via raw HTTP or cURL is blocked by Cloudflare WAF design.

Status & Restrictions

Raw HTTP requests to https://agentrouter.org/v1 without client spoofing headers fail with unauthorized client detected.

AgentRouter enforces Cloudflare Web Application Firewall (WAF) checks specifically targeting unofficial automated clients.

Required WAF Bypass Headers

To emulate an authorized client in direct HTTP requests, you must append these 3 headers:

Originator: codex_cli_rs
Version: 0.101.0
User-Agent: codex_cli_rs/0.101.0 (Mac OS 26.0.1; arm64) Apple_Terminal/464

Base URL: https://agentrouter.org/v1

Recommended Alternatives

Instead of raw Direct API calls, use one of the supported integration paths:

Option 2: Coding Agents ✅ Claude Code, Cline, Cursor, Roo Code / Kilo Code. Option 3: Desktop Apps ✅ Claude Desktop, Cowork, Cursor.
