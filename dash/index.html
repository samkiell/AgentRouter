Direct API (Raw HTTP / cURL)

direct-api/ on GitHub →

Directly calling AgentRouter base URL in custom code via raw HTTP/cURL is blocked by Cloudflare WAF design without spoofing headers.

Required WAF Bypass Headers

If attempting direct requests from custom scripts, Cloudflare WAF returns unauthorized client unless client headers are spoofed:

Originator: codex_cli_rs
Version: 0.101.0
User-Agent: codex_cli_rs/0.101.0 (Mac OS 26.0.1; arm64) Apple_Terminal/464

Claude Code CLI

          
    
            
  1. Install: npm install -g @anthropic-ai/claude-code
    2. 
            
  2. Set environment variables:
              
    export ANTHROPIC_BASE_URL=https://agentrouter.org
export ANTHROPIC_AUTH_TOKEN=sk-your-api-key
export ANTHROPIC_API_KEY=sk-your-api-key
export ANTHROPIC_MODEL=claude-opus-4-8
    
            
    3. 
            
  3. Run: claude
    4. 
          

        


        
        

          
Claude Code (VS Code Extension)

          
Open VS Code User Settings JSON (Cmd/Ctrl+Shift+P → Open User Settings (JSON)) and add:

          
{
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "sk-your-api-key" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://agentrouter.org" },
    { "name": "ANTHROPIC_MODEL", "value": "claude-opus-4-8" }
  ],
  "claudeCode.disableLoginPrompt": true
}

        


        
        

          
Cline Extension

          
    
            
  • 
              Claude Models: API Provider = Anthropic · Custom Base URL = https://agentrouter.org (NO /v1) · Model = claude-opus-4-8
            
    • 
            
  • 
              GPT Models: API Provider = OpenAI Compatible · Base URL = https://agentrouter.org/v1 · Model = gpt-5.6-sol
            
    • 
          

        


        
        

          

            
Cursor IDE

            
Settings → Models → OpenAI API Key. Enable "Override OpenAI Base URL" and set to https://agentrouter.org/v1.

          

          

            
Roo Code / Kilo Code

            
Custom Provider profile: Anthropic Base URL = https://agentrouter.org or OpenAI Base URL = https://agentrouter.org/v1.

          

        

      

    


    
    

      

        

          

            Desktop Apps · Confirmed Working ✅
            
Desktop Applications Integration

          

          
            desktop-apps/ on GitHub →
          
        

        
Use AgentRouter inside Claude Desktop, Cowork, Cursor, or any desktop AI application supporting custom API endpoints.

      


      

        

          
General Endpoint Rule

          

            

              Claude / Anthropic Style
              Base URL: https://agentrouter.org (NO /v1)
            

            

              OpenAI Style
              Base URL: https://agentrouter.org/v1 (WITH /v1)
            

          

        


        

          
Claude Desktop Instructions

          
    
            
  1. Open Claude Desktop settings.
    2. 
            
  2. Locate Custom Provider / Custom Endpoint fields.
    3. 
            
  3. Set Base URL to https://agentrouter.org
    4. 
            
  4. Paste your AgentRouter API key.
    5. 
            
  5. Select model: claude-opus-4-8 or claude-opus-5.
    6.
