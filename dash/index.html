Required WAF Bypass Headers

AgentRouter WAF blocks standard HTTP requests without client fingerprint spoofing. Include these 3 headers on every call:

Originator: codex_cli_rs
Version: 0.101.0
User-Agent: codex_cli_rs/0.101.0 (Mac OS 26.0.1; arm64) Apple_Terminal/464

Base URL: https://agentrouter.org/v1

Common API Errors Reference

      

        

          unauthorized client
          Missing WAF headers (Originator, Version, User-Agent). Always send all 3 headers.
        

        

          content-blocked
          Triggered prompt safety filter. Rephrase prompt or switch between GPT / Claude models.
        

        

          no available channel
          Target model is temporarily over capacity. Wait a few seconds or switch models.
